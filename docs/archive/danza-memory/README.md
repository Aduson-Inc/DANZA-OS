# DANZABOSS Auto-Memory

Durable, append-friendly knowledge the system has learned about ITSELF (distinct
from `.danza/` runtime state, which is about the *target app* being built).

Each file = one durable fact/topic. `INDEX.md` is the load-first pointer list.
Convention: append new learnings with a dated bullet; do not rewrite history
(mirrors Constitution Rule 36, append-only).
